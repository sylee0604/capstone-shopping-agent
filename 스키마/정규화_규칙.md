# 사이즈표 추출·라벨링 정규화 규칙 (v1.2, 2026-10-05)

## 1. 기본 원칙
- **이미지에 적힌 그대로 기록한다.** 판매자 실수(중복 라벨, 오타, 역전된 값)도 고치지 않고 notes에 "원본 오류"로 남긴다.
- 판단이 필요한 항목(단위, 단면/둘레, 소매 기준)은 근거를 notes에 적는다. 판단할 수 없으면 `불명`.
- 값이 `/`, `-`, 빈칸이면 기록하지 않는다(null).

## 2. 단위
| 원문 | 기록 |
|---|---|
| 斤 (진) | ÷2 해서 kg으로 저장, weightUnit = `斤` (1斤 = 0.5kg, 중국 본토 기준) |
| kg, 公斤, 千克 | 그대로, weightUnit = `kg` |
| 단위 없음 | 키 대비 BMI로 추정 → `추정_斤` 또는 `추정_kg` (예: 키 126cm에 53 → kg이면 BMI 33이므로 斤) |
| 개월(个月) | ÷12 해서 ageYears |
| 범위 `100-110`, 단일값 `110` | [100, 110], [110, 110] |
| 상한 없음 `14岁以上` | [14, null] |
| `90/100` (키 범위를 /로 표기) | [90, 100] |

## 3. 둘레 치수 (胸围·腰围·臀围)
| 원문 | value | basis |
|---|---|---|
| `36*2`, `35×2` | 36, 35 | 단면 |
| `胸围1/2` 머리글 | 적힌 값 | 단면 |
| 그 외 | 적힌 값 | 값의 크기로 판단 (예: 아동 100 사이즈 가슴 45 → 단면, 70 → 둘레) |
| 신축 범위 `74-84` | [74, 84] | 판단 |

- "平铺测量(펼쳐서 측정)" 문구만으로 단면이라고 판단하지 않는다. 같은 문구가 있어도 둘레 값인 표가 있었다.
- 같은 표 안에서도 칸마다 기준이 다를 수 있다(가슴 둘레 + 허리 단면).

## 4. 소매
| 원문 | from |
|---|---|
| 袖长 (어깨부터) | 어깨 |
| 连肩袖长, 또는 袖长이지만 값이 화장 수준 | 목 (화장 = 어깨너비 절반 + 소매) |

## 5. 기본 칸과 extra
- 기본 칸: 키, 몸무게, 나이, 총장(衣长·裙长·裤长·总长), 가슴, 허리, 엉덩이, 어깨, 소매
- 그 외(下摆, 袖口, 脚口, 裤脚, 档深, 前档, 后档, 股下, 大腿围, 后中长, 充绒量 …)는 `extra`에 **원문 머리글: 원문 값**으로 기록
- 머리글이 같아도 재는 방법이 다르면 기본 칸에 넣지 않는다.

## 6. 표 구조
- 사이즈가 가로로 나열된 표도 사이즈별 행으로 바꿔 기록한다.
- 치수 표와 권장 키·몸무게 표가 따로 있으면 사이즈 라벨 기준으로 합친다.
- 한 이미지에 표가 여러 개(버전별)면 `variants`로 나누고, 버전 전체에 붙은 권장 키는 `fitHeightCm`에 기록한다.
- 길이 버전(小个子/常规款/高个子)이 열로 나열된 표도 버전별 `variants`로 나누고 각 버전의 length에 값을 넣는다.
- 총장 머리글이 둘 이상(衣长 + 裙长)이면 length는 비우고 둘 다 `extra`에 넣는다.
- 치수가 아닌 속성 칸(备注, 是否开裆 등)은 기록하지 않는다.
- 키 × 몸무게 매트릭스는 `fitMatrix`에 기록한다. 칸 찾기(판정)는 코드가 한다.
- 표가 다음 이미지로 이어지면 두 이미지를 한 문제로 묶는다.

## 7. 소재
- 사이즈표 이미지에는 거의 없다(25장 중 3장). 소재는 상세 페이지의 상품 속성 텍스트에서 가져온다.
